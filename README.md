# 公式仕分けくん

**図形を見て、公式をえらぼう。**

小学生向けの、図形の公式を「覚える」だけでなく、**図形を見て、何を求めるのかを判断し、正しい公式を選ぶ**練習ができるWebアプリです。

## 🌐 Webアプリ

https://tt-sensei.github.io/kousiki-siwake/

## ✨ 特徴

- 図形を見ながら、対応する公式を選択
- 学習段階に合わせた3レベル構成
- 公式集で、挑戦前に確認できる
- 30秒チャレンジで、短時間でも取り組める
- 正解・不正解のフィードバックをその場で表示
- 得点や結果を記録
- 学習の達成に応じてコレクションを集められる
- PC・タブレット・スマートフォンに対応
- インストール不要でブラウザから利用可能

## 📚 レベル

### LEVEL 1　基本の平面

基本的な平面図形を中心に学習します。

- 長方形・正方形などの面積
- 三角形の面積
- 平行四辺形の面積
- 台形の面積
- 円の面積
- 円周

### LEVEL 2　平面＋立体

平面図形に加えて、立体の体積まで扱います。

- 平面図形の面積
- 円の面積・円周
- 立方体・直方体の体積
- 柱体などの体積

### LEVEL 3　ごちゃまぜ＋逆算

複数の公式から必要なものを判断する発展レベルです。

- 平面・立体の公式を混ぜて出題
- 求めるものを判断する問題
- 公式を使った逆算
- 公式を使いこなす練習

## 🎯 学習の流れ

**公式集 → チャレンジ → 結果**

まず公式を確認し、図形と「求めるもの」を意識してからチャレンジします。

特に、次の3点を意識して学習できるようにしています。

1. 図形名を確認する
2. 何を求めるのかを確認する
3. それに合う公式を選ぶ

単純な公式暗記ではなく、**「この図形で、この量を求めるなら、この公式」**という判断につなげることをねらいとしています。

## 🏅 コレクション

チャレンジの結果に応じてコレクションを集められます。

学習を繰り返すモチベーションづくりとして、ゲーム的な要素を取り入れています。

## 👨‍🏫 想定する使い方

授業の導入・復習、朝学習、すき間時間、家庭学習などでの利用を想定しています。

特に、公式をただ暗記するのではなく、**図形と求める量を手がかりに公式を選ぶ力**を育てるための補助教材として利用できます。

## 📖 コンセプト

公式は、覚えるだけでは使えるようになりません。

「何の図形か」
「何を求めるのか」
「どの公式を使うのか」

この判断を繰り返すことで、公式を実際の問題解決に使える知識へつなげることを目指しています。
